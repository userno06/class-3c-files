# CLASS C FILES

A digital student archive and interactive class website created by KOI for BSIT Class C.

The website showcases the students, personalities, information, and memories of the class through an interactive and experimental web experience.

---

About the Project

**CLASS C FILES** is a creative web project designed to present our class as a digital archive.

The project focuses on:

- Student profiles
- Interactive navigation
- Smooth scrolling
- Animated transitions
- Student photo cards
- Interactive visual effects
- Responsive web design
- Creative typography
- Audio and visual experiences

The goal is to turn a simple class directory into a more immersive and memorable digital experience.
